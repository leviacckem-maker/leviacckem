Work flow

{FLOW工作流}

作为主要竞品都具有的专业版功能，竞品之一的After ship 采用标准工作流，但其工作流的板块常被吐槽"太复杂搞不懂"

功能形态部分参考竞品
IOOP
问题

标准工作流 以 Yes/no 的逻辑判断来运行分支，且条件/动作 支持在每个节点进行插入和多级嵌套，但具象到当前系统的业务场景来说，并用不上多条分支逻辑，反而增加理解成本

方案

采用单线程流式逻辑 简化工作流，以正向场景(yes)运行，同时条件的多级判断合并单张卡片，流程中只支持插入动作，条件固定在起点，极大程度减少工作流复杂度

核心原则

工作流 = 优先规则

满足规格中配置的条件时生效，已配置动作层级优于通用设置

通用设置 = 默认逻辑

系统默认规则，处理所有未被工作流覆盖的订单
